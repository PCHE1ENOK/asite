# Скриншоты экранов (golden-рендер)

Все снимки получены **из golden-тестов** (`test/screenshots/screenshot_test.dart`):
Flutter рендерит виджеты приложения в PNG в headless-режиме, без Windows и без
устройства. **Снимков из реального запуска пока нет** — приложение ещё не
запускалось на ПК или телефоне.

Особенности рендера:
- данные — тестовые ответы AniList (`test/fixtures/`), не живой API;
- обложки и баннеры — сгенерированные градиенты, сеть не используется;
- японские названия показываются квадратиками: в тестовой среде нет
  CJK-шрифта (на устройствах его подставляет система);
- «Версия…» — в тестах нет данных пакета; кнопка входа неактивна, потому что
  тестовая сборка без `GITHUB_CLIENT_ID`.

Пересоздать:

```
flutter test test/screenshots --update-goldens --dart-define=SCREENSHOTS=true
```
