# Компоненты и состояния

Каждый компонент описан тем, как он ложится на Flutter. Токены — `tokens.json`, доступ из виджетов через `Theme.of(context).extension<AppTokens>()`.

## Общие правила состояний

| Состояние | Правило | Flutter |
|---|---|---|
| Наведение | слой `fg` с альфой 0.06 поверх поверхности; постер — scale 1.03 + тень e2 | `WidgetStateProperty` для `overlayColor`, `MouseRegion` + `AnimatedScale` |
| Нажатие | слой 0.12 | `overlayColor` в `WidgetState.pressed` |
| Выбрано | `accentSoft` фон + текст `accent` | `WidgetState.selected` |
| Фокус | кольцо 2px `accent`, отступ 2px, только при навигации с клавиатуры | `FocusableActionDetector`, `FocusHighlightMode.traditional` |
| Отключено | непрозрачность 0.38, курсор по умолчанию | `WidgetState.disabled` |
| Загрузка | скелетоны той же геометрии, что и контент, мерцание `skeleton` → `skeletonShine` 1.2 с | общий `Skeleton` виджет, при reduce motion — без мерцания |
| Пусто | иконка 48 `fg3`, одна фраза что здесь будет, одна кнопка действия | `EmptyState(icon, text, action)` |
| Ошибка | что случилось + как исправить, кнопка «Повторить»; уже показанные данные не убираем | `ErrorState(message, onRetry)` |

## Список

- **PosterCard** — обложка 2:3 (`AspectRatio`), радиус md (`ClipRRect`), ScoreBadge, ListStatusDot, полоса прогресса 3px. Под обложкой заголовок 2 строки (`maxLines: 2, overflow: ellipsis`), caption. Размеры задаёт сетка (`SliverGrid` с `SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 220, childAspectRatio: ...)`).
- **ScoreBadge** — `averageScore` целым числом; текст цвета good/warn/bad, фон тот же цвет 12% поверх затемнения `#000000A0` на постере (на постере всегда тёмная подложка, чтобы читалось на любой обложке). Нет оценки — «—» `fg3`. Высота 22, радиус xs, `tabularFigures`.
- **AdultBadge** — «18+», высота 20, радиус xs, фон `#B9302F`, белый текст 11/600 (контраст 5.9:1, одинаково в обеих темах). На постере под ScoreBadge, на карточке тайтла — первым в строке мета.
- **SyncBar** — полоса на `surface1` с рамкой `border`, радиус md: иконка состояния, текст (жирное начало + пояснение), справа одна кнопка (outline или tonal). `Semantics(liveRegion: true)`.
- **SyncDot** — точка 10 на пункте профиля в навигации, обводка 2px цвета фона.
- **DeviceCodeField** — код `display` 28 с разрядкой, кнопка «Копировать» (`Clipboard.setData`) → тост «Код скопирован».
- **Switch** — трек 44×24 радиус pill: выкл. — `surface3` с рамкой `borderStrong`, ручка `fg2` (6.2:1 к треку); вкл. — `accent`, ручка `onAccent`. Роль `switch`, вся строка настроек кликабельна. На iOS — `CupertinoSwitch`, на Android — `Switch` M3.
- **SearchField** — высота 48, радиус md, рамка `borderStrong`, в фокусе `accent` 2px. Подсветка совпадений в подсказках — `accent` 35% под текстом `fg`.
- **SettingsGroup / SettingsRow** — заголовок `overline`, строки на `surface1` с общей рамкой; слева подпись + пояснение `fg2`, справа один контрол.
- **ListStatusDot** — круг 24 цвета статуса с белой иконкой; рядом с цветом всегда иконка (без опоры только на цвет).
- **StatusButton** — `MenuAnchor`: кнопка с иконкой и подписью текущего статуса, меню из 5 статусов + «Удалить из списка». Без статуса: «Добавить в список».
- **FilterChip / SortMenu** — высота 32, радиус pill, рамка `border`; выбранный — `accentSoft` + `accent`. Сортировка — `MenuAnchor` с галочкой у текущего пункта.
- **TabBar** — подчёркивание 2px `accent`, счётчик в капсуле `surface2`.
- **StatusBar** — составная полоса 10px, сегменты в порядке CURRENT → PLANNING → COMPLETED → PAUSED → DROPPED, зазор 2px цвета поверхности, концы скруглены 4px. Под ней легенда с иконкой, подписью и числом (подписи обязательны: в светлой теме у трёх цветов контраст с фоном < 3:1).
- **ScoreHistogram** — 10 столбцов (10…100), один цвет `accent`, тонкие столбцы с зазором, скругление верхних концов 4px, ось без сетки кроме базовой линии, подписи значений на трёх самых высоких столбцах, тултип по наведению «80 баллов · 24 310 чел.». Таблица-альтернатива доступна для скринридера (`Semantics`).
- **ContinueCard** — 16:9, кадр серии, «Серия 6 · осталось 14 мин», прогресс.
- **EpisodeRow** — высота 56; номер (tabular), название, длительность, состояние (не начата / прогресс / просмотрена / не вышла).
- **DubPicker** — поповер 320 шириной на `surface2` (в плеере — на `#161923E6` с blur 24), строки 44, выбранная с галочкой. От 7 вариантов: заголовки групп «Озвучка» / «Субтитры», поле фильтра сверху, максимум 60% высоты экрана, прокрутка (`MenuAnchor` + `ListView`). Один вариант: просто подпись, без стрелки.
- **NextEpisodeCard** — 320×(кадр 16:9 + 56), радиус lg, кольцо отсчёта 2px `accent`, кнопки «Смотреть сейчас» (filled) и «Отмена» (text). Escape = Отмена.
- **Toast** — снизу по центру (в плеере — сверху), `surface3`, радиус md, до 2 действий, 3 с.

## Кнопки

| Вариант | Фон | Текст | Высота | Радиус |
|---|---|---|---|---|
| Filled | `accent` | `onAccent` | 40 (36 compact на desktop-панелях) | sm |
| Tonal | `accentSoft` | `accent` | 40 | sm |
| Outline | прозрачный, рамка `borderStrong` | `fg` | 40 | sm |
| Text | прозрачный | `accent` | 36 | sm |
| Icon | прозрачный | `fg2` → `fg` при наведении | 40×40 | pill |

Минимальная зона нажатия на iOS — 44×44.
